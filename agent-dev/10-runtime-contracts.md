# 10 Runtime Contracts

本文件定义不可静默弱化的 Chrome MV3、安全、隐私、权限、网络、存储和成本契约。任何运行时代码、配置或数据流任务都必须读取。

## 1. 运行时边界

```text
Popup / Options（可信扩展页）
          │
          ▼
MV3 Service Worker（唯一密钥与 Provider 网络层）
          │                    ▲
          ▼                    │
按需 Translator Script（低权限） ── 网页 DOM（不可信）
          │
          ▼
模型输出（不可信，校验后仅作纯文本）
```

- Service Worker 是唯一可以读取 API Key、完整 Provider 配置和发起模型请求的业务上下文。
- Translator Script 只处理段落 ID、源文本、目标语言和已校验译文；不得读取 Storage 或接触密钥。
- 网页、内容脚本传入数据、模型输出和远端错误响应都视为不可信。
- Service Worker 随时可能被 Chrome 回收。任务正确性不得只依赖内存全局状态。

## 2. 权限契约

Manifest 基线权限仅为：

- `activeTab`：用户点击后临时访问当前 HTTP/HTTPS 标签页。
- `scripting`：按需注入本地构建的 `translator.js`。
- `storage`：保存配置、会话级/本机级 Key 和本地用量。
- `optional_host_permissions: ["https://*/*"]`：仅作为运行时可申请范围。

必须遵守：

- 安装时不静态申请 `<all_urls>`，不注册常驻所有网站的内容脚本。
- API 请求前只申请用户配置 Base URL 对应的 HTTPS Origin。
- 网站级自动翻译未来需要单独请求该网站 Origin，并提供清晰撤销入口。
- 新增权限前必须写明用户价值、触发时机、数据范围和更小权限替代方案，并经用户确认。
- 构建后检查实际生成的 Manifest，不能只检查 `wxt.config.ts`。

## 3. API Key 与存储契约

- 默认把 API Key 保存到 `storage.session`；用户明确选择后才进入 `storage.local`。
- `storage.local` 和 `storage.session` 必须限制为 `TRUSTED_CONTEXTS`，兼容性回退不得静默扩大读取者。
- Key 不得通过运行时响应回填到 Popup/Options；界面只接收 `hasApiKey` 等脱敏状态。
- Key 不得进入内容脚本、网页 DOM、URL、日志、错误文本、通知、遥测、缓存、用量账本、测试或截图。
- 持久保存前必须说明它不是操作系统级加密保险箱。
- 切换保存模式时清除另一存储区的旧 Key；清除操作应覆盖两处。
- 不引入 `storage.sync` 保存密钥。

## 4. 消息与身份契约

- 所有跨上下文消息使用判别联合，并在运行时校验类型、字段、长度和来源；TypeScript 类型不等于运行时验证。
- `TRANSLATE_BATCH` 等页面来源消息必须确认 `sender.tab`，不得信任消息内自报 tabId、URL 或 Origin。
- 内容脚本不得提供任意请求 URL、认证头、Provider 类型或模型参数覆盖可信设置。
- 每个响应明确区分成功和标准化错误，禁止把远端完整 body 或认证信息透传到网页。
- 批次响应必须校验 blocks 数量、唯一 ID、ID 集合和字符串字段；畸形响应不得部分写入 DOM。

运行时消息、公开设置、操作结果和翻译批次以 `src/core/schemas.ts` 的 Zod schema 为边界来源。新增或修改消息字段时必须同时更新 schema、推导类型和正反测试，不得退回直接类型断言。

## 5. 网络与 Provider 契约

- Base URL 必须为有效 HTTPS URL；禁止凭字符串前缀校验协议。
- Provider 请求地址从可信设置构造，不跟随内容脚本提供的 URL。
- MVP 仅支持 OpenAI Chat Completions 兼容协议；不同认证或响应结构应新增适配器，不堆叠隐式分支。
- 请求设定超时、Abort 信号、有限并发和有限重试。401/403/402/404 不自动重试；429/5xx/网络错误只按明确策略重试。
- 同一条件下重试必须有上限和退避；停止新任务不能假装已取消在途请求。
- 系统提示必须把网页内容标为数据，不允许其改变指令；禁用工具调用和远程代码执行。
- 真实网页文本只直接发送给用户选择的模型服务商，不经过项目服务器。

## 6. DOM 与内容安全契约

- Translator Script 只在用户显式触发后注入，并只处理当时可见的阅读内容。
- 必须排除 `script`、`style`、`noscript`、`pre`、`code`、表单、可编辑和隐藏区域。
- 译文只能通过 `textContent` 或等价纯文本 API 渲染；禁止 `innerHTML`、脚本 URL、事件属性或动态执行。
- 不删除、覆盖或持久修改原文。重复运行必须复用或更新既有译文，不重复插入。
- 停止后不得开始新批次；局部失败保留原文和已完成结果。
- 不绕过付费墙、登录墙、验证码、robots 限制或页面访问控制。

## 7. 隐私与收集契约

- MVP 不包含账号、项目中转服务器、遥测、广告 SDK、浏览历史或自动问题上传。
- 兼容性报告默认只在本地生成并允许预览、删改；完整 URL、正文、表单内容和截图都需要独立明确同意。
- 日志只记录标准化状态和非敏感计数，不记录页面正文、Key、完整请求/响应或私人 URL。
- 新数据字段必须写明目的、位置、生命周期、访问者、清除方式和是否离开设备。

## 8. 成本与预算契约

- “无插件订阅费”不等于“免费翻译”；界面必须说明模型厂商可能收费。
- 成本展示默认称为“预估”，内置价格必须包含币种、更新时间和来源，并允许用户覆盖。
- 优先采用 Provider 返回的标准化 usage；缺失时明确标为估算，不伪造精确值。
- 每日账本按用户本地日期、Provider 和模型聚合，不包含 Key 或网页正文。
- 50%、80%、100% 阈值同一日期各提醒一次；预算默认关闭。
- 达到 100% 默认提醒而非硬阻断。可选暂停只阻止新任务，不承诺阻断已经在途或模型厂商账户层的费用。
- 任何定价公式、默认阈值、硬停止行为或价格远程更新都属于产品决策，修改前需用户确认。

## 9. 发布安全门

发布候选必须证明：

- 构建 Manifest 没有静态全站内容脚本或超出文档的权限。
- 构建产物和测试夹具不含真实 Key、认证头或个人路径。
- 不含远程可执行代码、`eval`、`new Function` 或模型输出 HTML 注入。
- 401、404、429、5xx、网络错误和畸形模型输出有受控失败路径。
- 隐私政策、权限说明、README 与实际数据流一致。
