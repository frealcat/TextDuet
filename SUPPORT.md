# Support

[中文](./SUPPORT.zh-CN.md)

Use [GitHub Discussions](https://github.com/frealcat/TextDuet/discussions) for installation help, Provider setup, API-cost questions, general usage, and ideas. Please search existing threads first.

Use an issue form when you can provide a reproducible bug, documentation correction, feature proposal, or public-site compatibility report. For security issues, use the private channels in [SECURITY.md](./SECURITY.md), never a public thread.

Before posting, remove API keys, passwords, credentials, private URLs, account information, unpublished text, request headers, and sensitive screenshots. TextDuet cannot recover a lost Provider key or resolve charges made by your model Provider; contact that Provider for account and billing support.
