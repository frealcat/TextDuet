# TextDuet 网站兼容与验收计划

## 1. 目标

首版不承诺“适配所有网站”，而是通过一组代表性网站和可重复的合成语料，覆盖文章、技术文档、讨论区、代码、数学公式、动态列表和复杂应用外壳等主要 DOM 模式。

测试分为两层：

1. **合成语料**：随仓库版本化，不依赖网络和登录，可做自动回归。
2. **真实网站**：使用公开页面做 Chrome 手工或 Playwright 冒烟测试，只保存断言和截图，不把第三方全文复制进仓库。

### 2.2 可重复的 Chrome 矩阵命令

仓库提供 `.playwright/extension-site-matrix.mjs`，通过 `npm run test:browser:sites` 执行。运行时把生产构建复制到临时扩展目录，只为公开页面 Origin 增加测试副本权限；生产 Manifest 不变。默认矩阵配置 16 个公开 URL：React/Vue/Svelte/Vite/Astro 官方文档、GitHub README、DEV/GitHub Community/TypeScript Issue/Lobsters、arXiv 和三个创意设计站；是否通过以最近一次可启动 Chrome Service Worker 的实际报告为准。

矩阵使用 Mock Provider 拦截测试 API Origin；请求体只在浏览器进程内解析为段落数量和字符计数，报告不写入正文、译文、Key、完整 URL 参数或响应。每页执行首次翻译、缓存复跑、代码/排除区快照、链接 click 事件、停止后新增段落断言；环境导航失败最多重试两次，并归类为 `environment-failed`，不伪装成插件兼容性失败。

默认退出门槛：至少 15 页通过，且 `framework-docs`、`readme-shell`、`overseas-community`、`academic`、`creative-design` 五类各至少 2 页；每页正文召回率 ≥90%，非正文误译率 ≤5%，重复译文为 0，译文必须为单一文本节点。可用 `TEXTDUET_SITE_IDS` 运行单页或分组诊断。

## 3. 发布阻塞标准

P0 网站每类至少选择两个实际可访问的公开页面，共不少于 15 个真实页面。发布候选版本需要满足：

- 正文可翻译文本块召回率不低于 90%。
- 导航、按钮、代码、表单等非正文误译率不高于 5%。
- 译文与源段落对应正确率为 100%。
- 重复点击翻译不产生重复译文。
- 停止后不再发起新模型请求。
- 页面原有链接、按钮、代码复制和折叠交互仍可用。
- 模型返回 HTML、事件属性或脚本字符串时只显示纯文本。
- 单页 1000 个候选元素的提取阶段不超过 100ms（测试机基线另行记录）。
- 不因某个段落失败而删除或覆盖原文。

P1 网站失败需要记录已知问题，但不阻塞首个 Alpha；P2 只收集结构特征与问题。

## 5. 真实网站样本选择规则

- 默认目标只选择无需登录、无验证码、无付费墙且在最近一次候选探测中实际可访问的公开页面。
- 访问受限或连续网络失败页面只进入探索清单，不计入默认目标数量、通过配额或产品失败数。
- 优先级依次为海外非中文社区、框架官方技术文档、创意设计内容，再补充 README 与学术页面的结构覆盖。
- 不绕过付费墙、验证码、地区限制或 robots 控制。
- 优先选择稳定的官方文档、帮助页和长期文章。
- 仓库只记录 URL、页面类型、日期、预期选择器统计和问题，不保存第三方全文。
- 对频繁变化的网站至少保留两个不同结构样本。
- 真实模型只用于人工质量抽查；结构回归统一使用 Mock Provider。

## 6. 未来自动发现需要适配的网站

### 6.1 用户主动报告

在扩展中提供“报告此网页兼容问题”，默认不上传。用户明确同意后生成一份可预览、可删改的诊断包：

- TextDuet 与 Chrome 版本。
- 主机名；完整 URL 和路径默认不包含，用户可选择加入。
- 候选节点数、已翻译节点数、失败批次数和标准化错误码。
- DOM 结构指纹：标签、ARIA role、深度和长度分布，不包含正文文本、属性值和表单内容。
- 用户选择的问题类型：漏译、误译、重复、布局、动态内容、性能或其他。
- 可选截图必须再次单独确认。

诊断包先下载到本地；后续可引导用户手动附加到 GitHub Issue。第一版不建立自动上传服务器。

### 6.2 GitHub Issue 模板

Issue 表单收集：网站域名、公开示例 URL、复现步骤、预期、实际、扩展版本、Chrome 版本、是否动态加载。明确提醒删除私人页面、账号信息和 API Key。

### 6.3 自动回归

- 使用 Playwright + Chrome，每周运行公开 URL 清单。
- 模型请求由 Mock Provider 拦截，记录提取节点与插入结果。
- 对关键统计做阈值断言，对页面结果保存脱敏截图。
- 页面因网络、登录墙或反自动化失败时标记为“环境失败”，不自动判定扩展回归。
- 连续三次结构变化后创建待人工确认的兼容性任务，不自动提交网站专用规则。

### 6.4 适配优先级

未来根据以下本地或自愿报告信号排序：

`优先级 = 报告用户数 × 严重度 × 可复现率 × 网站通用性`

任何遥测或自动报告在正式设计前保持关闭；不得为了兼容性收集完整浏览历史、网页正文、API Key、输入框内容或私人 URL。
