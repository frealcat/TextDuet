# TextDuet 0.2.0 发布说明

[English](./RELEASE-NOTES-0.2.0.md)

> **草案 / 尚未发布。** 本文描述计划中的首次公开 `0.2.0` 版本，并不表示
> Chrome Web Store 条目或 GitHub Release 已上线。在维护者记录最终产物前，
> 不要补写发布日期、商店链接、扩展 ID、校验和或已发布声明。

## 发布范围

TextDuet `0.2.0` 将已验证的本地翻译流程，与首次公开发布所需的安全、隐私、
文档和分发准备合并。Chrome Web Store 是推荐安装渠道；GitHub Release ZIP
和源码构建继续面向高级用户与贡献者。

最终发布必须从已审阅的确切提交和安装包构建。门禁完成前，本文件有意保持为草案。

## 主要变化

- 翻译用户在当前标签页主动选择的可见阅读文本，支持双语、仅原文和仅译文模式。
- 支持 OpenAI、Qwen、DeepSeek、OpenRouter、SiliconFlow 及自定义端点等
  OpenAI 兼容 HTTPS 服务商。
- 通过 Chrome 右键菜单翻译选中文本；页面运行期间可按需处理动态内容。
- 复用有边界的本地译文，查看本地 Token 账本，并设置可选的预算提醒。
- 支持仅当前会话 API Key，或使用密码解锁的本地保险箱进行加密持久化；保险箱
  密码永不保存。
- Provider 请求、密钥处理和存储访问均限制在可信扩展上下文中；Translator
  代码不能读取 Chrome 扩展存储。
- Provider 输出经过校验后按纯文本渲染，绝不作为 HTML 或可执行代码执行。
- 提供中英文文档、安装路径、隐私材料、贡献规则和社区问题反馈指引。

## 安全与隐私

只有用户主动启动后才会翻译。符合规则的网页文本从 Chrome 直接发送到用户选择
的服务商；TextDuet 不运营翻译中转服务器、账号后端、遥测、广告、云同步或自动
问题上传。所选服务商可能保存数据、收取请求费用，或依据自身规则进行训练和处理。

`0.2.0` 定义两种 Key 保存模式：

- **仅当前会话：** Key 只在浏览器会话中可用，Chrome 重启后清除。
- **本地保险箱：** 本地模式 Key 与持久译文缓存保存在版本化 AES-GCM 加密信封中。
  解锁材料仅留在浏览器会话内；重启 Chrome 后保险箱会锁定，需用户再次解锁。

密码不会持久化。锁定或清空保险箱会移除持久密钥和缓存的访问能力；当前页面的
内存复用仅能在本次页面会话中继续。旧版明文 Key 和按 Origin 映射必须在发布前迁移
或删除。

首次向服务商请求前，扩展必须展示版本化隐私确认，说明网页文本会直接发送、服务商
可能收费以及服务商负责数据处理。公开数据流和权限边界见[隐私政策](./PRIVACY.zh-CN.md)
与 [Chrome 权限说明](./CHROME-PERMISSIONS.zh-CN.md)。

## 翻译与回归覆盖

本版本目标包含 active/inactive 可见性回归修复：标签页恢复可见时只执行幂等对账，
不得再次插入 TextDuet 译文区域。真实的重复导航项或阅读项仍应分别成为候选；翻译
记忆复用不能替代节点归属。

候选边界继续排除 TextDuet 自有节点、按钮、表单控件、可编辑字段、代码、隐藏内容
及其他交互控件。动态页面、SPA 导航、虚拟列表、不同容器中的重复文本，以及停止、
取消和错误路径，都必须在发布前完成浏览器验证。

## 安装渠道

| 渠道 | 目标用户 | 更新方式 |
| --- | --- | --- |
| Chrome Web Store | 大多数用户；推荐 | Chrome 管理的自动更新 |
| GitHub Release ZIP | 高级用户和测试者 | 手动下载并重新加载 |
| 源码构建 | 贡献者和开发者 | `npm ci` 后本地构建 |

商店安装、手动加载和源码构建可能拥有不同的扩展 ID 与独立 Chrome 存储。不要假设
API Key、保险箱记录、缓存或用量历史会在渠道之间迁移。通过 `chrome://extensions`
加载前必须先解压 ZIP。

## 兼容性与已知边界

- 目标平台是 Google Chrome Manifest V3。Edge、Firefox、Safari、Chrome 内部页面、
  Chrome Web Store、登录墙、付费墙、验证码及其他受保护页面不在支持范围内。
- 动态页面和 SPA 页面按尽力支持处理；网站可能随时改变 DOM。
- 按钮、表单、可编辑字段、代码、隐藏内容和 TextDuet 自有 DOM 会被有意排除。
- Provider 请求费用由用户承担；用户应先查看服务商的价格、限制、留存和数据处理规则。
- 本次公开 UI 与文档只提供 `en` 和 `zh-CN`。
