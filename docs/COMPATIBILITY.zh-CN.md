# 网站兼容性

[English](./COMPATIBILITY.md)

TextDuet 在用户主动启动后，翻译普通 HTTP/HTTPS 网页中符合规则的阅读文本。它不会绕过登录墙、付费墙、验证码、受保护浏览器页面、Chrome Web Store 页面或其他访问控制。

## 预期边界

- 翻译目标是可见阅读文本；具有实际阅读意义的导航链接可能被纳入。
- 按钮、表单控件、可编辑字段、代码、隐藏内容和 TextDuet 自身插入的节点会被排除。
- 动态页面和 SPA 以尽力而为的方式支持；网站可以随时改变结构。
- 只有用户启动翻译后才会翻译；项目不安装常驻全站内容脚本。
- 若页面变得不稳定，或继续翻译可能带来不需要的 Provider 费用，请停止翻译。

## 报告公开网站问题

若问题可在无需登录的公开 URL 上复现，请使用网站兼容性 Issue 表单。请提供简短描述、扩展版本、Chrome 版本、操作步骤、预期结果和实际结果。

不得包含 API Key、私密 URL、账号信息、受限网页正文、完整 Provider 请求/响应或敏感截图。扩展可生成仅本地预览的脱敏诊断；下载或附加前请先自行审阅。

## 问题处理方式

兼容性修复会按严重程度、可复现性、用户影响和是否存在安全的通用解决方案排序。若某个页面专用规则会扩大网页访问范围、翻译交互控件、降低安全性，或产生与收益不成比例的长期维护成本，项目可能拒绝该规则。

一般支持问题而非可复现 Bug，请前往 [GitHub Discussions](https://github.com/frealcat/TextDuet/discussions)。
